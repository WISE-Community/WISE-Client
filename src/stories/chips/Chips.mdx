# Chips

<p>WISE chips are used to display information in a compact form. They can also allow users to make selections, filter content, and enter data.</p>
<p>Chips are always used inside a container. To create chips, start with a container element (`<mat-chip-set>`, `<mat-chip-grid>`, or `<mat-chip-listbox>`) and nest `<mat-chip>` elements inside.</p>
<p>WISE uses a customized version of the <a href="https://material.angular.io/components/chips/overview" target="_blank">Chips</a> component from <a href="https://material.angular.io" target="_blank">Angular Material</a>. Check out the Angular Material documentation for more information.</p>
